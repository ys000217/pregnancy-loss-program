# 细胞组成（胎盘细胞比例）

妊娠丢失队列中，由甲基化/参考图谱推断的胎盘主要细胞类型比例：按 **孕周（6–12 周）** 与 **临床三分组** 做差异检验与作图。

> 原始比例矩阵与推断脚本若仍在本地其他目录，大文件不入库；本模块提交**汇总表与图**。

## 结果（`results/`）

### 6–12 周（孕周趋势）

| 文件 | 说明 |
|------|------|
| `6-12周全细胞统计.csv` | 各细胞类型按周描述统计 |
| `6-12周全细胞差异检验汇总.csv` | 全局检验 + 两两显著比较 |
| `6-12周全细胞堆叠图.png` / `趋势图.png` | 组成与趋势 |
| `6-12周_*_箱线图.png` | 分细胞类型箱线 |

**摘要（入库表）：**

- **Trophoblasts**：孕周间差异显著（全局 P≈0；多对周次显著）
- **Endothelial**：全局 P≈0.008（如 10 vs 12 周等）
- Hofbauer 边缘；nRBC / Stromal / Syncytiotrophoblast 全局不显著

## 解读注意

细胞比例随孕周变化（尤其滋养层）是预期生物学现象；三分组无显著不表示甲基化异常与组成无关，需在特定分析（如 abnormal）中单独做组成校正敏感性。
